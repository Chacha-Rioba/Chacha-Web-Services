# CWS AWS-reference rebuild

Reference inspected: https://aws.amazon.com/ on 2026-09-29, both retrieved content and a fully loaded desktop browser view.

Implemented: two-tier utility/main navigation, expandable solution/resource menus, service search, account links, a rotating hero content panel, original animated infrastructure artwork, feature cards, tabbed service discovery, a five-item solution carousel, industry filtering, an interactive delivery model, project calls to action and a categorized footer. Existing public pages, configurator and portals share the new navy/blue/lavender theme. All key cards use whole-card links. Motion can be paused and respects reduced-motion preferences.

Scope boundary: this is a CWS website based on the reference's presentation patterns, not a copy of AWS's complete website or cloud platform. CWS retains its actual service catalog. No AWS product capabilities, customer stories, infrastructure regions, free credits, certifications or provisioning functions are represented as CWS capabilities. Original CWS copy and graphics replace AWS proprietary content and assets. Real compute, storage, database and AI cloud offerings would require a separately defined infrastructure project.

Validation: production build; API integration; browser checks for desktop/mobile navigation, project submission, email signup, photography and service navigation, global search/category filtering, solution carousel, industry filtering, delivery controls and hero/reduced-motion controls. Existing SMTP, file scanning and launch limitations remain in IMPLEMENTATION-STATUS.md.
